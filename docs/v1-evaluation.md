## 3. 统一验收表

| 维度 | 说明 | 结果 |
|---|---|---|
| 事实 | claims 与来源映射、示意标注 | 图表均标注"示意/教学示例"；**未经真人事实复核** |
| 叙事 | 开场现象、解释链、结尾回扣 | 三题均回扣开头；质量由 AI 审稿判断，非人工 |
| 视觉 | 画面与口播对应、多个视觉节拍 | 每镜至少一个真实画面图层；同 cut ≥3 种视觉签名 |
| 长短版 | 独立编排 | 长版 9 镜、短版 3–4 镜，短版重新组织而非截取 |
| 声音 | 配音、节拍、音乐 | 真实 Edge TTS + 词语边界；混音/原声比 1.2–1.25（<1.6）；**未实听** |
| 稳定 | 失败可恢复、不重复生产、不覆盖旧交付 | 同题复用、`--new`、`revise` 新 revision、`--reuse-script` |
| 可复现 | 版本、hash、时间线 | `manifest.json`、`制作溯源.json`、`metrics.csv`、`storyboard.json` |

人工观感 1–5 分（叙事清晰 / 视觉贴合 / 声音自然 / 字幕可读 / 愿意看完）：**未评分**。
不填任何数字，避免把 AI 判断写成人工评测。
